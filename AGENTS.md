# VXL project instructions

Read CODEX-HANDOFF.md and README.md before editing. This is a dependency-free HTML/CSS/JavaScript prototype, not a starter to replace.

## Scope and delivery

- Current task: develop the main page and its premium animation/video treatment.
- Work in isolation. The user now wants one continuously updated private working-preview link to avoid repeated ZIP downloads. That separate preview is authorized; preserve the live company website and its hosting/domain settings.
- Preserve dark/light themes, anchor navigation, mobile menu, logo and actual VXL photographs.
- Keep the supplied company logo artwork intact; its whitespace is cropped by the display container only.
- Use the user's reference sites for motion/design direction. Do not copy their branding, business claims or media.
- Retain readable text, clean whitespace and responsive layouts.
- Preserve native scrolling, keyboard access, visible focus indicators and semantic content.
- Muted decorative video must have a poster and pause control. Respect OS reduced-motion, save-data preference, background tabs and off-screen playback.
- Do not add CMS, login, forms, routes or backend infrastructure merely to facilitate a visual edit. These need explicit scope.

## Project commands

- `npm run dev`: Node preview at http://127.0.0.1:4173.
- `npm run check`: syntax checks; no installation step.
- Assets belong in `assets/`; the server allows only public files and single-level asset paths.

## Verify each substantive motion change

Check desktop/mobile layout and both themes. Exercise pause/resume and reduced motion, theme switching, mobile menu, off-screen video pausing and media loading. Capture fresh screenshots when the visual result changes. Do not claim real-device testing unless it happened. Keep CODEX-HANDOFF.md updated with material changes and unresolved limits.
